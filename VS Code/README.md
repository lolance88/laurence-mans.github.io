# Wedding Website

A simple static wedding website for Emma and Alex.

## Files

- `index.html` — single-page wedding site
- `styles.css` — responsive visual design
- `script.js` — mobile menu behavior

## How to use

1. Open `index.html` in a browser.
2. Customize the content for your couple, venue, and itinerary.
3. Replace placeholder email and venue details as needed.

## Deployment

This site can be hosted on any static web host such as GitHub Pages, Netlify, or Vercel.
